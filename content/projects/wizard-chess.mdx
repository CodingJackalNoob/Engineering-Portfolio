## Overview

Wizard Chess is a real-life magnetic chessboard that moves its own pieces. The system uses a belt-driven XY carriage beneath the board to drag pieces into position with an electromagnet. The mechanism keeps motors out of view and gives the board a physical, game-like movement system.

This project is being developed with Divyank Shah's Instructables project as a reference design.

## Design Process

The initial design scope focuses on a compact XY-plotter layout, magnetic piece control, an Arduino Uno control system, and reliable belt and rail hardware.

## Hardware and Software

- Arduino Uno for motion control
- Belt-driven XY carriage
- Electromagnet for piece actuation
- C++ firmware for automated movement

## Current Progress

The project began in September 2026 by scoping the mechanical layout and selecting the rail, belt, and electromagnet hardware.
